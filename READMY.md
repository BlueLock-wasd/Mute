# 🎵 Mute — Music Platform

> 🚧 **ВНИМАНИЕ: Это скелет (базовая версия) проекта!** 
> Данный репозиторий представляет собой фундамент для полноценной музыкальной платформы. Проект находится в активной разработке, и многие функции (указанные в разделе "Roadmap") будут добавлены позже. Сейчас это отличная демонстрация навыков работы с Flask, SQLAlchemy, JavaScript (SPA) и Chart.js.

**Mute** — это веб-платформа для прослушивания и обмена музыкой, вдохновлённая современными стриминговыми сервисами. Пользователи могут загружать свои треки, слушать их через встроенный плеер и отслеживать свою статистику.

## ✨ Реализованный функционал (на данный момент)

- **Кастомный музыкальный плеер:** 
  - Очередь воспроизведения с возможностью перетаскивания (Drag & Drop).
  - Мини-плеер и полноэкранный режим.
  - Вращающаяся обложка (анимация) и работающая полоса прогресса.
- **Интерактивный аудио-визуализатор:** Неоновая волна, которая реагирует на басы (Canvas API).
- **SPA-переходы (Single Page Application):** Музыка не прерывается при переходе между страницами благодаря AJAX и History API.
- **Система аутентификации:** Регистрация, вход и разграничение ролей (Пользователь / Администратор).
- **Загрузка треков:** Загрузка файлов с автоматическим считыванием длительности (через `mutagen`) и загрузкой обложек.
- **Профиль пользователя:** Статистика (прослушивания, топ-жанры, самые длинные треки) с визуализацией данных через **Chart.js**.
- **Живой поиск:** Поиск по названию и исполнителю с выпадающим списком.

## 🗺 Roadmap (Планы по доработке)

Чтобы проект стал полностью рабочим, в будущем планируется реализовать:
- [ ] **Импорт треков из JSON:** Массовая загрузка треков через файл конфигурации.
- [ ] **Парсинг внешних источников:** Интеграция с API (ВКонтакте, SoundCloud) для наполнения раздела «Сейчас популярно».
- [ ] **Умная очередь:** Доработка логики перемешивания (Shuffle) и избранного (Favorites).
- [ ] **Оптимизация:** Кэширование, сжатие обложек и вынос тяжелых скриптов (Chart.js) на отдельные страницы.
- [ ] **Социальные функции:** Комментарии к трекам и система подписок.

## 🛠 Технологии

- **Backend:** Python, Flask, Flask-Login, Flask-WTF
- **База данных:** MySQL, SQLAlchemy ORM
- **Frontend:** HTML5, CSS3 (Custom Glassmorphism), JavaScript (Vanilla JS), Bootstrap 5
- **Библиотеки:** Chart.js (графики), Mutagen (чтение метаданных MP3)

## 🚀 Как запустить локально

### 1. Клонирование репозитория
```bash
git clone https://github.com/BlueLock-wasd/Mute.git
cd Mute

### 2. Создание виртуального окружения
python -m venv venv

# Windows:
venv\Scripts\activate

# Mac/Linux:
source venv/bin/activate

### 3. Установка зависимостей
pip install -r requirements.txt

### 4. Настройка базы данных
1. Создайте базу данных в MySQL:
CREATE DATABASE mute_platform;
2. Создайте файл .env и укажите ваши данные для подключения (пароль от MySQL и т.д.).
   SECRET_KEY=****
   DATABASE_URL=***

### 5. Инициализация БД и создание администратора
python init_db.py

### 6. Запуск приложения
python app.py

### 7. Переход в браузер
Откройте в браузере: http://127.0.0.1:5000/
```
